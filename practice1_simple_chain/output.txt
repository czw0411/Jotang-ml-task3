==============================================================================
实践 1：简单计算链的梯度   f(x, y) = (x*y + x^2)^2
==============================================================================
选取的输入： x = 2.0, y = 3.0

一、前向传播：把计算拆成 4 个基本步骤（节点值会保留下来）
    [1] u = x * y        = 2.0 * 3.0 = 6.0
    [2] v = x * x        = 2.0 * 2.0 = 4.0
    [3] s = u + v        = 6.0 + 4.0 = 10.0
    [4] f = s * s        = 10.0 * 10.0 = 100.0

二、反向传播：从 f 出发逆着计算图走（链式法则）
    [1] df/df = 1
    [2] df/ds = df/df * 2s            = 1 * 2*10.0 = 20.0
    [3] df/du = df/ds * 1             = 20.0
    [4] df/dv = df/ds * 1             = 20.0
    [5] df/dx = df/du * y + df/dv * 2x
              = 20.0 * 3.0 + 20.0 * 4.0 = 140.0
        df/dy = df/du * x            = 20.0 * 2.0 = 40.0
        （x 同时进入 u 和 v 两条路径，所以梯度要相加；y 只有一条路径）

三、四份结果对照
    方法                                       f         df/dx         df/dy
    ----------------------------------------------------------------------
    NumPy 手算（按计算图反向）        100.000000    140.000000     40.000000
    闭式解 2s(y+2x), 2sx              100.000000    140.000000     40.000000
    中心差分（h=1e-6）                        --    140.000000     40.000000
    PyTorch autograd                  100.000000    140.000000     40.000000
    ------------------------------------------------------------------
    NumPy 手算 vs PyTorch 的最大绝对误差： df/dx = 0.000e+00, df/dy = 0.000e+00
    中心差分 vs PyTorch 的最大绝对误差： df/dx = 1.805e-09, df/dy = 5.591e-09
    结论：手算梯度与 PyTorch autograd 一致
