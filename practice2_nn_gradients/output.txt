==============================================================================
单样本 (n = 1) 与 小 batch (n = 8) 的形状对比
==============================================================================
    变量             n = 1     n = 8   说明
    X               (1, 2)    (8, 2)   只有第 0 维（batch 维）变了
    W1              (2, 4)    (2, 4)   权重与 batch 无关
    b1                (4,)      (4,)   偏置与 batch 无关
    Z1              (1, 4)    (8, 4)   逐元素运算，形状跟着 batch 走
    A1              (1, 4)    (8, 4)   同 Z1
    W2              (4, 1)    (4, 1)   与 batch 无关
    b2                (1,)      (1,)   与 batch 无关
    Z2              (1, 1)    (8, 1)   同 Z1
    P               (1, 1)    (8, 1)   同 Z1
    loss                ()        ()   对 batch 取平均，永远是标量
    dL/dW1          (2, 4)    (2, 4)   沿 batch 维求和后，batch 维消失
    dL/db1            (4,)      (4,)   沿 batch 维求和后，batch 维消失
    dL/dZ2          (1, 1)    (8, 1)   每个样本一个误差信号 (P - Y)/n

公式层面的变化只有两处：
    1) dL/dZ2 = (P - Y) / n：n = 1 时就是 P - Y，n = 8 时每个样本只摊到 1/8；
    2) dL/db1、dL/db2 变成沿 batch 维求和 sum(axis=0)。前向里 b 被广播到了每个
       样本，反向时必须把广播出去的梯度加回来；n = 1 时求和退化成它自己，
       所以单样本的代码看不出这个动作。
    矩阵乘法的写法（X.T @ dZ1、A1.T @ dZ2）在两种 n 下完全一样，形状自动对上。

==============================================================================
故意写错的两版：练习判断误差来自哪里
==============================================================================

错误 1：把 Y 写成一维 (n,)，而不是 (n, 1)
    P 的形状 (8, 1)，Y.ravel() 的形状 (8,)
    P - Y.ravel() 的形状 = (8, 8)   <- 广播把 (8,1) 和 (8,) 撑成了 (8,8)
    dL/dW2 = A1.T @ dZ2 的形状 = (4, 8)   <- 正确时是 (4, 1)
    对角线元素 [0,0] = 0.67528124，它只是忘了除 n 的版本（正确的 dL/dZ2[0,0] = 0.08441015，相差 8 倍）；非对角线的 7 列全是跨样本硬凑出来的值。
    定位方式：先打印 shape。形状不对的时候，数值比较没有任何意义。

错误 2：忘记除以 batch 大小 n
    dL/dW2（漏掉 /n）与 PyTorch 的最大绝对误差 = 7.011e-01
    dL/dW2（正确）  与 PyTorch 的最大绝对误差 = 2.602e-17
    漏掉 /n 的梯度恰好是正确值的 8.0 倍（n = 8）
    指纹：形状完全正确、所有参数梯度同比例放大 —— 这正是求平均方式不一致的表现。

错误 3：矩阵转置方向写反（例如把 dL/dW1 = X.T @ dL/dZ1 写成 dL/dZ1.T @ X）
    这种错误通常连形状都对不上；万一形状碰巧对上，就只能靠与 PyTorch 的
    逐项数值比较来定位。所以先查形状，再查缩放，最后逐元素对比。

==============================================================================
结论
==============================================================================
    单样本  n = 1：NumPy 手算与 PyTorch 的最大绝对误差 = 1.110e-16
    小 batch n = 8：NumPy 手算与 PyTorch 的最大绝对误差 = 2.602e-17
    对照：漏掉 /n 的错误版本误差量级 = 7.011e-01，比浮点噪声大十几个数量级
    两边在 float64 下逐项一致，说明手写的链式法则、形状变换、求平均方式都正确。
